# HKScreener Pro - 香港股权筛选智能终端 🚀

HKScreener Pro 是一款专为香港证券市场设计的轻量级、零配置、极速响应的专业股权筛选与数据可视化智能终端。该终端完全在您的本地安全运行，采用现代化的全宽暗黑视效（Bloomberg 风格）与全中文本土化交互，旨在为您提供媲美专业量化金融终端的选股与投资分析体验。

---

## 🎨 核心设计与 UI 架构 (Aesthetics & Architecture)

- **彭博级全宽大屏终端架构 (Bloomberg Terminal Style)**：摒弃传统挤压式的侧边栏与窄分栏，采用 100% 全宽流式布局。顶部全宽平铺港股三大核心指数，所有数据表格与深度图表获得 100% 宽幅全屏展露。
- **Bloomberg 极客暗黑主题**：基于深邃的蓝黑色调渐变背景（`#090a0f` 至 `#121520`），全面缓解看盘疲劳，营造高度专注的专业量化视觉。
- **高阶毛玻璃设计（Glassmorphism）**：各功能卡片和指数面板采用毛玻璃质感（`backdrop-filter: blur(10px)`）搭配微光边界，悬停支持动态微升与外发光效果。
- **中国特色“红涨绿跌”配色**：完全对齐 A 股/港股习惯，红色代表升，绿色代表跌，提供极佳的图形数据阅读体感。

## 🗺️ 九大核心功能模块 (Key Features)

### 1. 🏛️ 香港大盘指数实时监控
- 页面顶部全宽平铺实时监测 **恒生指数 (HSI)**、**恒生科技指数 (HSTECH)** 和 **恒生国企指数 (HSCE)** 的最新交易价格、点数涨跌和百分比涨跌幅。
- 在任何标签页均可一目了然把握大盘动向。

### 2. 🗺️ 当日港股资金集中度矩阵图 (Grid Heatmap Matrix)
- 自动抓取并展示当日港股交易最活跃的前 **48 只吸金龙头股**。
- 采用**纯 CSS Grid 响应式卡片网格**与 JavaScript 高度自适应，保证无多余滚动条且字样 100% 洁净呈现。
- **排序**：按个股成交总金额降序排布，直观展现资金集中度。
- **悬浮窗 (Tooltip)**：鼠标悬浮实时展示最新价、今日涨跌、当日成交额（亿 HKD）及昨收价格。

### 3. 💡 四大快捷量化策略模板（一键参数联动）
- 内置四大经典量化与估值选股策略，支持一键在筛选控制台自动映射所有关联参数：
  - **💰 高股息蓝筹**：寻找公用事业、金融服务、房地产领域的港股巨头（市值 >50亿 USD，PE <12，股息率 >6%）。
  - **🚀 低估值成长**：聚焦科技、生物医药、通讯行业成长股（PE <22，市值 >10亿 USD，流动性强）。
  - **🦄 小市值黑马**：挑选小盘估值极低标的（市值 1亿~10亿 USD，PE <10，股息率 >2%）。
  - **📖 巴菲特财报**：应用巴菲特护城河财务法则（毛利率 >40%、净利率 >20%、销管费 <30%、ROE >15%、负债可在 4 年还清、资本支出 <25%）。

### 4. 🔍 港股多因子智能筛选控制台（折叠/展开）
- 支持基于顶部折叠式控制台的复杂条件联立筛选：
  - **规模因子**：最小/最大市值区间（美元）。
  - **估值因子**：最大市盈率 (PE Trailing) 限制。
  - **流动性因子**：最小日均成交量（股）。
  - **价格与动量**：股票价格区间（港币）、最低涨跌幅限制（%）。
  - **收益率与行业**：最低股息率限制、多行业板块多选筛选。
  - **🔒 巴菲特深度财报指标过滤**：支持深入校验资产负债表与现金流量表等多因子。

### 5. 🇨🇳 港股通（Stock Connect）双向筛选
- 对接新浪财经港股通（`hgt_hk`）实时接口，每日动态拉取 640+ 只港股通成分股名单，完成两端代码自动转换（如 `00700` 对齐为 `0700.HK`）。
- **三种模式**：`不限` / `仅限港股通`（追踪“北水”主力资金） / `排除港股通`（挖掘未被内资覆盖的高弹性标的）。

### 6. 📊 15+ 深度财务指标与 10x 线程池并发计算
- 在筛选列表中除了基本价格与市值外，全面新增高阶财务指标：
  - **资产净利率 (ROA%)**
  - **股价/每股净资产 (PB)**
  - **研发投入 (亿)**
  - **无形资产/净资产 (%)**
  - **现金/净资产 (%)**
  - **现金流是否为正**
- 采用 **`ThreadPoolExecutor(max_workers=15)` 10 倍速多线程并发拉取**，几十只股票的数据渲染只需不到 2 秒。

### 7. 📊 个股深度图表及全球三大市场 PE 横向对比
- 展示个股的详细高品质名片与财务基本面。
- **🌐 全球三大市场同行业 PE 横向对比**：实时并发拉取 **🇭🇰 港股、🇺🇸 美股、🇨🇳 A股** 同行业平均市盈率，自动生成估值偏离度与三档颜色徽章（🟢偏低 / 🟡合理 / 🔴偏高）。
- 提供个股过去一年日 K 收盘价走势曲线及每日成交量分布图。

### 8. 🏆 股神持仓动态跟踪 (Buffett, Duan, Li Lu)
- 实时追踪全球顶级价值投资大师的核心持仓：
  - 🧙‍♂️ **沃伦·巴菲特 (Warren Buffett)**：苹果、谷歌、美国运通、美国银行、可口可乐、雪佛龙等 13 只标的。
  - 🎯 **段永平 (Yongping Duan)**：苹果、伯克希尔B、谷歌、腾讯控股、泡泡玛特、阿里巴巴等 8 只标的。
  - 🏔️ **李录 (Li Lu)**：美国银行、谷歌、伯克希尔A、美光科技、华美银行等 6 只标的。
- 醒目展示三位投资家各自的 **核心哲学** 与 **4 大投资风格与选股法则提醒**。
- 提供 9 列精美持仓表格，包含 **持仓占比(%)**、最新价、今日涨跌、距 52 周高位偏离度等。

### 9. 📰 大盘与个股聚合舆情动态 & 汉化报表导出
- 自动拉取选中个股及选股池前 5 只股票的最新重大新闻，按时间倒序高亮展示。
- 针对 100% 中文化表格，支持一键导出为标准的 `.csv` 文件。

## 🛠️ 技术栈与数据流 (Architecture)

- **核心语言**：Python 3.12
- **展示框架**：Streamlit (构建交互式 UI 与数据流绑定)
- **多线程并发**：`concurrent.futures.ThreadPoolExecutor` (10x 筛选加速)
- **数据源**：
  - **Sina Finance API**：动态拉取港股通股票名单和大盘实时成交数据。
  - **Yahoo Finance API**：拉取个股基本面、三大市场行业平均 PE、历史 K 线、13F/持仓及新闻舆情数据。
- **性能优化**：引入 Streamlit 分层缓存机制（`@st.cache_data`），保证单股详情与大盘行业数据的零延迟加载。

## 🚀 快速启动指南

### 1. 安装依赖
请在您的终端运行以下命令安装运行所需的依赖包：
```bash
pip install streamlit yfinance pandas requests
```

### 2. 本地启动
进入项目目录并执行：
```bash
streamlit run hk_screener.py
```
启动成功后，浏览器会自动打开：[http://localhost:8501](http://localhost:8501)

## 💡 使用小贴士

* **重置条件**：点击筛选控制台中的 **「🧹 重置所有条件」** 即可瞬间将所有因子还原为默认值。
* **数据加载慢？**：因为项目在本地安全运行并直连 Yahoo Finance 获取实时数据，极少数情况下若数据拉取较慢，通常与本地网络和 Yahoo 接口的连通质量有关。
