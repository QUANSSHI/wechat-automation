# HKScreener Pro - 香港股权筛选智能终端 🚀

HKScreener Pro 是一款专为香港证券市场设计的轻量级、零配置、极速响应的专业股权筛选与数据可视化智能终端。该终端完全在您的本地安全运行，采用现代化的暗黑视效（Bloomberg 风格）与全中文本土化交互，旨在为您提供媲美专业量化金融终端的选股体验。

---

## 🎨 核心设计与视觉美学 (Aesthetics & UX)

- **Bloomberg 极客暗黑主题**：基于深邃的蓝黑色调渐变背景（`#090a0f` 至 `#121520`），全面缓解看盘疲劳，营造高度专注的专业量化视觉。
- **高阶毛玻璃设计（Glassmorphism）**：各功能卡片和指数面板采用毛玻璃质感（`backdrop-filter: blur(10px)`）搭配微光边界，悬停时支持动态微升（Scale-up）和外发光光晕效果。
- **中国特色“红涨绿跌”配色**：完全对齐 A 股/港股习惯，红色代表升，绿色代表跌，提供极佳的图形数据阅读体感。

## 🗺️ 八大核心功能模块 (Key Features)

### 1. 🏛️ 香港大盘指数实时监控
- 首页头部实时监测 **恒生指数 (HSI)**、**恒生科技指数 (HSTECH)** 和 **恒生国企指数 (HSCE)** 过去 24 小时的最新交易价格、点数涨跌和百分比涨跌幅。
- 采用卡片式动态呈现，上涨标红，下跌标绿。

### 2. 🗺️ 当日港股资金集中度矩阵图 (Grid Heatmap Matrix)
- 自动抓取并展示当日港股交易最活跃的前 **48 只吸金龙头股**。
- 采用**纯 CSS Grid 响应式卡片网格**（拒绝树状图在小方块时的极端压缩和字样遮挡），保证任何屏幕尺寸下文字 100% 洁净呈现。
- **排序**：按个股成交总金额降序（从左上到右下）排布，直观展现资金集中度。
- **悬浮窗 (Tooltip)**：鼠标悬浮展示详情气泡，实时展示当前最新价、当日成交额（亿 HKD）、今日涨跌以及主力资金净流入规模。

### 3. 💡 快捷量化策略模板（一键参数联动）
- 内置三大常用经典量化选股策略，支持一键在侧边栏自动映射所有关联参数：
  - **高股息蓝筹龙头**：筛选金融服务、公用事业、房地产领域的龙头。设定：市值 > 50亿 USD，市盈率 < 12，股息率 > 6%。
  - **低估值成长先锋**：聚焦科技、医疗、通讯服务。设定：估值 PE < 22，市值 > 10亿 USD，具备较强流动性。
  - **小市值黑马探测**：挖掘小盘黑马股。设定：市值在 1亿~10亿 USD 之间，PE < 10，股息率 > 2%。

### 4. 🔍 多因子交互式筛选终端
- 支持基于侧边栏的多维度复杂条件联立筛选：
  - **规模因子**：最小/最大市值区间（美元）。
  - **估值因子**：最大市盈率 (PE Trailing) 限制。
  - **流动性因子**：最小日均成交量（股）。
  - **价格区间**：最低/最高股票价格（港币）。
  - **行业分类**：支持多选行业板块（完全中文化展示）。
  - **收益率因子**：最低股息率限制。
  - **动量因子**：最低涨跌幅限制。

### 5. 🇨🇳 港股通（Stock Connect）双向筛选
- 对接新浪财经港股通（`hgt_hk`）实时接口，每日动态拉取 640+ 只港股通成分股名单，完成两端代码自动转换（如 `00700` 对齐为 `0700.HK`）。
- **三种模式**：
  - `不限`：显示所有符合因子的股票。
  - `仅限港股通`：保留港股通标的，方便追踪“北水”主力资金。
  - `排除港股通`：剔除港股通，利于挖掘未被内资覆盖的高弹性潜在标的。

### 6. 📊 个股深度图表及财务指标分析
- 允许选择已筛选出的股票或手动输入任意港股代码（兼容 `0700` 等简写自动补全）。
- 展示个股的详细高品质名片（包含最新价、市盈率 PE、远期市盈率、股息率、贝塔系数 Beta）。
- 提供个股**过去一年日K收盘价走势曲线**以及**过去一年每日成交量分布图**。

### 7. 📰 大盘与个股聚合舆情动态
- **大盘/个股焦点新闻**：若无选中个股，默认拉取恒指焦点新闻；选中个股后，自动过滤当前个股的最新相关资讯。
- **选股池个股新闻聚合**：当点击执行筛选后，自动拉取选股池前 5 只股票的最新消息并按时间精确倒序排列，自带关联个股代码高亮高阶徽章。

### 8. 📥 汉化报表一键导出
- 对表格内容、状态标签、警示信息以及行业大类完成 100% 汉化。
- 支持将筛选好的精美数据表格一键导出为标准的 `.csv` 本地文件。

## 🛠️ 技术栈与数据流 (Architecture)

- **核心语言**：Python 3.12
- **展示框架**：Streamlit (构建交互式 UI 与数据流绑定)
- **可视化支持**：原生 CSS Grid / Apache ECharts CDN (渲染热力图)
- **数据源**：
  - **Sina Finance API**：动态拉取港股通股票名单和大盘实时成交数据。
  - **Yahoo Finance API**：拉取个股基本面、历史 K 线、历史成交量及新闻舆情数据。
- **性能优化**：引入 Streamlit 缓存机制对大盘指数、港股通名单、新闻等慢速 IO 进行长效内存缓存，极大保证了页面交互的零卡顿。

## 🚀 快速启动指南

### 1. 安装依赖
请在您的终端运行以下命令安装运行所需的依赖包：
```bash
pip install streamlit yfinance pandas requests
```

### 2. 本地启动
进入项目目录并执行：
```bash
streamlit run hk_screener.py
```
启动成功后，浏览器会自动打开：[http://localhost:8501](http://localhost:8501)

## 💡 使用小贴士

* **重置条件**：点击侧边栏的 **「🧹 重置筛选条件」** 即可瞬间将所有因子还原为默认值。
* **数据加载慢？**：因为项目在本地安全运行并直连 Yahoo Finance 获取实时数据，极少数情况下若数据拉取较慢，通常与本地网络和 Yahoo 接口的连通质量有关。
