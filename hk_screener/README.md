# 📊 HKScreener Pro - 香港股权筛选智能终端

HKScreener Pro 是一款专为香港证券市场设计的轻量级、零配置、极速响应的专业股权筛选与数据可视化智能终端。

---

## 🚀 快速启动

\\ash
# 进入项目目录
cd hk_screener

# 安装依赖
pip install streamlit yfinance pandas requests

# 启动 Streamlit 服务
streamlit run hk_screener.py
\启动成功后，浏览器会自动打开：[http://localhost:8501](http://localhost:8501)

## 🎨 界面美学与设计架构 (UI & Aesthetics)

- **彭博级全宽大屏流式终端架构 (Bloomberg Terminal Architecture)**：100% 全宽画面，顶部全宽平铺三大核心指数，所有数据表格与深度图表全屏铺展。
- **Bloomberg 极客暗黑主题**：基于深邃蓝黑渐变背景（\#090a0f\ 至 \#121520\），缓解看盘疲劳。
- **高阶毛玻璃视效 (Glassmorphism)**：玻璃质感卡片配合微光边界与动态微升效果。
- **红涨绿跌配色**：完全符合 A 股/港股视觉习惯（红升绿跌）。

## 🗺️ 核心功能模块

### 1. 🏛️ 香港大盘核心指数全宽监控
- 页面顶部实时监测 **恒生指数 (HSI)**、**恒生科技指数 (HSTECH)** 和 **恒生国企指数 (HSCE)** 核心点数与涨跌幅。

### 2. 📊 当日港股资金集中度矩阵图 (Grid Heatmap Matrix)
- 抓取当日成交额前 48 只吸金龙头股。
- 纯 CSS Grid 响应式卡片网格与 JS 动态适应，无多余滚动条。
- 悬浮窗 (Tooltip) 展示最新价、今日涨跌、成交额（亿 HKD）及昨收价格。

### 3. 💡 四大快捷量化策略模板
- **💰 高股息蓝筹**：公用事业/金融/地产龙头（市值 >50亿 USD，PE <12，股息率 >6%）。
- **🚀 低估值成长**：科技/医药/通讯成长股（PE <22，市值 >10亿 USD）。
- **🦄 小市值黑马**：小盘极低估值标的（市值 1亿~10亿 USD，PE <10，股息率 >2%）。
- **📖 巴菲特财报**：应用巴菲特护城河财务法则（毛利率 >40%、净利率 >20%、销管费 <30%、ROE >15% 等）。

### 4. 🔍 多因子智能筛选控制台 (可折叠/展开)
- 支持基于规模、估值、流动性、动量、收益率及巴菲特深度财报指标的多因子联立筛选。

### 5. 🇨🇳 港股通成分股双向筛选
- 实时接入新浪财经 640+ 只港股通成分股，支持 \不限\ / \仅限港股通\ / \排除港股通\ 模式。

### 6. 📊 15+ 深度财务指标与 10x 线程池并发
- 支持 ROA%、PB、研发投入、无形资产/净资产%、现金/净资产%、现金流正负校验。
- 基于 \ThreadPoolExecutor(max_workers=15)\ 实现几十只股票 2 秒内极速渲染。

### 7. 🌐 全球三大市场 PE 横向对比
- 实时并发拉取 **🇭🇰 港股、🇺🇸 美股、🇨🇳 A股** 同行业平均市盈率，自动生成估值偏离度与 🟢偏低/🟡合理/🔴偏高 三档徽章。

### 8. 🏆 股神持仓动态跟踪 (Buffett, Duan, Li Lu)
- 实时追踪沃伦·巴菲特、段永平、李录三大价值投资大师的最新持仓标的与持仓占比(%)。
- 醒目展示三位大师各自的 **核心哲学与 4 大选股法则提醒**。

- **Python 3.12** + **Streamlit**

- **concurrent.futures.ThreadPoolExecutor** (多线程并发加速)
